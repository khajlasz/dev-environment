# AI Workflow

## Roles

### ChatGPT
- Architecture
- Design reviews
- Learning and explanations
- Prompt engineering
- Complex reasoning

### OpenCode + Local LLM
- Daily implementation
- Repository analysis
- Refactoring
- Test generation
- Documentation

## Principle

Discuss the architecture first with ChatGPT.
Implement using OpenCode with the local model.
Return to ChatGPT for reviews, trade-off analysis and difficult design decisions.
